
1. def 로 함수 만드는 모양: def 로 시작하고, 함수 이름, 괄호 안에 받을 값, 콜론
2. print 와 return 의 차이를 한 줄로: 계산한 값을 돌려주고 함수를 끝내지만 print는 돌려주지 않고 바로 보여준다
3. from 모듈 import 함수: 파일에서 함수를 가져온다.
4. if __name__ == "__main__": 을 언제 쓰는지: 이 파일을 직접 실행할 때만 아래 코드를 실행하고, 다른 파일에서 import할 때는 실행하지 않는다는 뜻으로 다른 스크립트에서 import할 때 테스트 코드나 출력이 자동으로 실행되면 안 되기 때문에 사
5. "w" 와 "a" 의 차이, 그리고 bash의 어떤 기호와 같은지: w는 bash의 >로 있던 내용 위에 덮어쓴다는 것, a는 bash의 >>로 끝에 이어 쓴다.
